# MONOLITH TV

**MONOLITH TV** — самостоятельный лаунчер Android TV, ориентированный на управление пультом, быстрый отклик и работу без интернета. Первое тестовое устройство — **BOXY / HP4421-BOXY, Android TV 11, 2 ГБ RAM, Amlogic S905X4**.

**Состояние: 0.1.4 pre-alpha (Cinema).** Версия 0.1.3 проверена на BOXY, но её сетка и боковая панель не устроили по дизайну. В 0.1.4 интерфейс принципиально переработан: полноэкранная сцена выбранного приложения и горизонтальная полка. Новая версия требует отдельной проверки на приставке.

Принципы: никаких рекламных и сетевых блоков; оригинальные иконки установленных приложений без перекраски и масок; крупные фокусные элементы; быстрый возврат к штатному Google TV Launcher.

В текущем preview: чёрный AMOLED-интерфейс с большой сценой выбранного приложения, горизонтальная полка с анимированным фокусом, компактная навигация сверху, адаптация под 720p/1080p, прокручиваемые настройки, оригинальные иконки, управление пультом, **разделы «Все» / «Избранное»**, добавление в избранное кнопкой **MENU**, **собственные настройки лаунчера** (плотность сетки, сортировка), сохранение настроек, вход в системные настройки Android и восстановление фокуса после перестановки карточек.

Пока не реализованы: скрытие приложений, резервное копирование и постоянная подпись обновлений. При первом тестировании новой версии производительность и D-pad нужно проверить на реальной приставке.

### Безопасная проверка новой версии на BOXY

GitHub Actions подписывает debug APK временным сертификатом. Попытка
установить 0.1.3 поверх `dev.monolith.tv.preview` завершилась ADB exit 1
(приватная задача моста #132); версия 0.1.2 осталась установленной (#133).
Точная причина отказа не указана мостом, но конфликт сертификатов возможен.

Для тестирования нового AMOLED-интерфейса без удаления данных добавлена
параллельная сборка `dev.monolith.tv.review`. Bridge устанавливает её из
артефакта `MONOLITH-TV-preview-debug` (файл `app-debug.apk`). Исходная
сборка `dev.monolith.tv.preview` отдельно сохраняется как
`MONOLITH-TV-standard-debug`. Штатный Google TV и прежние настройки не меняем.

### Сборка

GitHub Actions проверяет тесты, Lint и компилирует debug APK. Для локальной сборки нужны JDK 17, Gradle 9.5, Android SDK 37 и AGP 9.3.

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APK из CI не имеет постоянной подписи. Для обновления поверх установленной версии подписи должны совпадать. **Удаление preview сотрёт его избранное и настройки.** Для полноценного канала обновлений требуется постоянный ключ подписи.

**Важно:** не удаляй Google TV Launcher. До проверки на BOXY тестируй MONOLITH TV обычным запуском приложения.
