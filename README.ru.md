# MONOLITH TV

**MONOLITH TV** — самостоятельный лаунчер Android TV, ориентированный на управление пультом, быстрый отклик и работу без интернета. Первое тестовое устройство — **BOXY / HP4421-BOXY, Android TV 11, 2 ГБ RAM, Amlogic S905X4**.

**Состояние: 0.1.2 pre-alpha.** Версия 0.1.1 с прежней сеткой и настройками проверялась на BOXY. Новый двухколоночный дизайн и улучшения экранов небольшой высоты в версии 0.1.2 ещё не установлены и не проверены на реальной приставке.

Принципы: никаких рекламных и сетевых блоков; оригинальные иконки установленных приложений без перекраски и масок; крупные фокусные элементы; быстрый возврат к штатному Google TV Launcher.

В текущем preview: обновлённая ТВ-галерея с боковой панелью выбранного приложения, адаптация под 720p/1080p, прокручиваемые настройки, оригинальные иконки, управление пультом, **разделы «Все» / «Избранное»**, добавление в избранное кнопкой **MENU**, **собственные настройки лаунчера** (плотность сетки, сортировка), сохранение настроек, вход в системные настройки Android и восстановление фокуса после перестановки карточек.

Пока не реализованы: скрытие приложений, резервное копирование и постоянная подпись обновлений. При первом тестировании новой версии производительность и D-pad нужно проверить на реальной приставке.

### Сборка

GitHub Actions проверяет тесты, Lint и компилирует debug APK. Для локальной сборки нужны JDK 17, Gradle 8.13 и Android SDK 36.

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APK из CI не имеет постоянной подписи. Для обновления поверх установленной версии подписи должны совпадать. **Удаление preview сотрёт его избранное и настройки.** Для полноценного канала обновлений требуется постоянный ключ подписи.

**Важно:** не удаляй Google TV Launcher. До проверки на BOXY тестируй MONOLITH TV обычным запуском приложения.
